# MPMS Backend - Minimal Project Management System

This is the backend API for **MPMS (Minimal Project Management System)**, built as part of a MERN recruitment task.

The system allows an Admin to manage projects, sprints, tasks, team members, and reports. Members can view assigned work, update task progress, add comments, and log time.
